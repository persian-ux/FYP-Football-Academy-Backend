Welcome back 👋

This is a public dashboard demo page. The SportSphere FAQ chatbot widget is fixed in the bottom-right corner (use the green chat bubble to try it).

It loads the predefined questions from the public REST API at /api/v1/chat/faqs/ and fetches each selected answer from /api/v1/chat/faqs/<id>/answer/.

Embedding elsewhere: include <script src="{% static 'chatbot/chatbot.js' %}"></script> and (optionally) set window.SportSphereChatbot = { apiBaseUrl: "..." } before it loads.
